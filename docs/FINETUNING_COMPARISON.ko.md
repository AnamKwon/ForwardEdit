# 파인튜닝 비교 설계

[프로젝트](../README.ko.md) · [English](FINETUNING_COMPARISON.md) · [보존된 결과](RESULTS.ko.md)

**상태: 미실행·사전등록 전 비교 설계입니다.** 현재 기록에는 충분히 학습한 파인튜닝 기준선이 없습니다. 12문장 AdamW 학습 동작 검사는 방법 비교에서 제외합니다. 그 검증 악화로 파인튜닝 전반의 약점을 주장할 수 없으며, 데이터 양의 효과도 분리해서 측정하지 않았습니다.

[실행 계약](INFERENCE_ONLY_CONTRACT.md)과 [기여 지침](../AGENTS.md)은 optimizer·LoRA 학습을 금지합니다. 이 문서는 예외를 허용하거나 학습 코드를 제공하거나 과거 스크립트를 되살리지 않습니다. 기존 외부 학습 산출물은 학습 없이 감사할 수 있지만, 새 학습 비교군에는 사용자가 명시한 예외와 별도 학습 작업공간이 필요합니다. 직접 편집 경로는 계속 추론 전용입니다.

## 비교 질문과 비교군

| 질문 | 데이터 조건 | 해석 |
|---|---|---|
| 적응 방법에 따른 효과는 무엇인가? | 편집과 파인튜닝에 같은 개발 자료·정답을 제공하고 실제로 읽은 범위를 공개 | 모든 조정 비용을 기록하는 공통 데이터 비교 |
| 실용적인 파인튜닝 대비 경쟁력이 있는가? | 파인튜닝에 충분한 과제 관련 데이터와 검증으로 고른 설정을 허용하고 편집기의 작은 데이터 노출량도 공개 | 서로 다른 데이터·자원 예산의 실용 비교 |

두 번째 비교에서 파인튜닝을 편집기의 몇 개 예시에 맞춰 제한하면 안 됩니다. 첫 번째도 12문장 검사를 반복하지 않고 의미 있는 크기의 자료를 사용해야 합니다. 두 결과를 분리해 보고하며, 이것만으로 데이터 양의 인과 효과를 분리했다고 주장하지 않습니다.

같은 원본 체크포인트·토크나이저·dtype에서 최강으로 측정한 무편집 프롬프트/decoding, LLM 직접 편집, 제대로 구성한 지도 파인튜닝, 적용 가능한 LoRA를 비교합니다. 적응 비교군은 선행 편집 없이 원본에서 시작합니다. 학습 범위와 구현상 차이를 공개합니다. 자원이 부족한 비교군으로 측정하지 않은 더 강한 기준선을 대신하지 않습니다.

## 데이터와 후보 선택

기록된 수학 과제는 006의 정확한 **Qwen3.5-0.8B** 원본 리비전을 사용합니다. 구체적인 자료 후보는 [공식 GSM8K 학습 분할](https://github.com/openai/grade-school-math)의 [7,473개 예시](https://huggingface.co/datasets/openai/gsm8k/blob/25fb0412dbcc2e5128322234d829fbd6ece72c7c/dataset_infos.json)이며, MATH 영역을 검사한다면 [MATH 학습 자료](https://github.com/hendrycks/math)를 보완합니다. 이는 사용 가능한 자료 후보이며 특정 개수가 충분하다는 보장은 아닙니다. 학습 전에 검증을 분리하고 필터링·중복 제거·검증 분리 후 실제 개수를 기록합니다. 공식 test 정답을 적응에 사용하지 않습니다. 출처 리비전·라이선스·입력 해시·정답 형식·고유 예시·고유 토큰·총 처리 토큰을 기록합니다.

TinyStories를 별도로 비교한다면 [공식 학습 자료](https://huggingface.co/datasets/roneneldan/TinyStories/blob/main/README.md)의 충분한 적격 자료와 분리된 검증·평가 자료를 사용합니다. 데이터 카드에 원래 모델의 학습 자료라고 명시되어 있으므로, 같은 자료의 추가 학습을 미관측 문장 학습으로 소개하면 안 됩니다. TinyStories 언어 모델링 결과와 Qwen 수학 점수를 섞어 방법 순위를 매기지 않습니다.

데이터 양·학습률 일정·정규화·중단 규칙·학습 범위·조정 예산은 개발/검증만으로 선택합니다. 학습 곡선과 선택한 체크포인트, 탈락한 설정과 실패한 실행도 보고합니다. 데이터만 늘렸다고 검증 성능이 좋아진다고 보장하지 않습니다. 독립 평가 전에 모든 선택 체크포인트와 평가 설정을 해시로 고정합니다. 이미 노출된 과거 test는 설명용 재평가 자료이며, 새 비교에는 평가자가 관리하는 선택 미사용 집합이 필요합니다. 공개 벤치마크가 모델 사전학습에서 제외됐다고 보장할 수는 없습니다.

[공식 Qwen 모델 카드](https://huggingface.co/Qwen/Qwen3.5-0.8B)의 생성 모드·샘플링 설명을 참고해 thinking 모드·프롬프트·파서·토큰 한도·종료 조건을 기록합니다. 같은 모드 안에서는 적응 모델과 무편집 모델에 공통 조건을 적용하고, 가장 강하게 측정한 적절한 무편집 설정도 별도로 보고합니다. 길이 잘림·파싱 실패·정답률을 구분합니다.

## 공통 평가와 보고

| 지표 | 모든 비교군의 보고 항목 |
|---|---|
| 목표 품질 | 과제에 맞는 정확도/NLL, 문항별 전후 변화와 불확실성 |
| 목표 과제 정답 보존 | 기존 정답 중 손실 / 기존 정답 수, 분자·분모·불확실성 |
| 비대상 과제 보존 | 사전에 정한 별도 과제와 모델별 같은 paired 평가 |
| 자원 | 자료·정답 준비, 조정, 편집기·대상 모델 추론, 학습, 시간, 장비, 토큰과 비용. 에너지는 측정 시에만 보고 |
| 선택 | 데이터·체크포인트 해시, 모든 시도, 선택 설정과 고정 기록 |

미리 정한 운용 조건에서 성능과 보존을 함께 보고합니다. 과거 5% 규칙은 보편 기준이 아닙니다. 과거 판정을 고치거나 새 test를 본 뒤 한도를 고르면 안 됩니다. 기존 정답의 분모가 작으면 불확실성과 충분한 평가 크기를 명시해야 합니다. 바뀐 가중치가 적다는 사실만으로 전체 비용이 적다고 주장하지 않습니다.

## Unaddressed criticisms / 미대응 비판

이 문서는 설계이며 어느 방법이 우세하다는 근거가 아닙니다. 적격 데이터·최종 데이터 양·검증 분할·학습 예산·기준선 설정·보존 과제·새 평가 자료를 실행 전에 고정해야 합니다. 공개 증거 묶음에는 원본 체크포인트와 과거 평가 자료 전체가 없습니다. 학습 이력이나 호환되는 평가가 없는 외부 체크포인트로 이 공백을 채울 수 없습니다. 이 문서를 위해 새 학습이나 독립 test는 실행하지 않았습니다.
