---
name: weight-space-mcp-only
description: Independently inspect, directly edit and evaluate local neural weights using only the ForwardEdit MCP, without shell access, gradient training or another MCP.
---

Use the registered ForwardEdit MCP for all analysis, weight writes, notes and inference. Call `edit_api_schema` before constructing plans: `scale.strength` is the removed fraction (0 means identity, 1 ablation), not a multiplication factor. The schema specifies every required field and vector/block axis; do not discover it by repeated failed guesses. No loop-engineering service is required. Read `experiment_info`, then load `skills/weight-space-engineer/SKILL.md` using `read_guidance`; follow its diagnosis, initial proposal, direct edits and preservation rules. Read linked guidance through the same tool when relevant. MCP tools do not automatically load skill bodies into a client.

`forward_and_wait` submits the same real `research_forward` job and returns its verified result; this avoids spending editor turns on repeated polling. A timeout does not cancel or authorize a duplicate submission. The saved `notes/submitted-forward-*.json` and ledger permit reattachment with `research_status`/`research_result`. Use the frozen generation settings for accuracy comparisons. Short generations are diagnostics and do not prove full-budget improvement.

Read development prompts/solutions with `development_examples`. Use `generation_window` for early/late windows of actual saved reasoning. Use `read_artifact` for bounded manifests, observations metadata and module configuration. Keep each job's artifact path, hash, model identity, ID and token position attached to derived quantities.

For wide vectors or matrices, read [CPU array operations](references/array-operations.md) through `read_guidance`. The MCP evaluates caller-specified arithmetic on hash-bound arrays; it does not select coordinates, directions or strengths. Inspect actual module axes and current weight entries, explain the numerical derivation and alternatives, and prepare the proposed edit before writing. A prepared local intervention is not a proven semantic mechanism or a performance gain.

Record hypotheses, predictions, falsifications and feedback with `record_observation`. Revise from actual parent results with `create_candidate_from_arrays(...,parent_candidate_dir=...,rationale=...)` or the existing `revise_candidate`; do not present independent preset variants as feedback-dependent revision. Verify source/parent/new values with `compare_candidate_parameters` and check actual loaded BF16 GPU changes in inference results. File changes that vanish at inference precision do not count as effective weight edits.

For repeated editing or trajectory analysis, read `skills/weight-space-engineer/references/adaptive-edit-loop.md` through `read_guidance`. Persist a case bank and hypothesis dispositions, replay the edited model's newly damaged/generated prefixes, and distinguish measured token probabilities from hidden-state projections. A failed local explanation calls for additional evidence or a revised mechanism, not an automatic freeze of the latest harmful probe.

When the development evidence supports one selection, call `freeze_candidate` once with the relevant job IDs and decision. If no candidate meets the declared improvement/preservation gates, say `no_gain` or `diagnostic_only`. Freezing records selection and hashes; the tool does not certify the decision. Independent withheld evaluation happens after editing stops, and cannot be used to reselect. A turn/forward budget is capacity, not a required number of edits or epochs. Finish with parameter evidence, feedback-dependent revisions, accuracy, losses of old correct answers, uncertainty and remaining limits.

Agree on whether a requested forward count is a capacity limit or a study-completion target. Do not claim a multi-pass study was performed when only a few successful batches ran. Early stopping needs an explicit scientific/resource reason and a record of the remaining depth; it must not manufacture edits to fill the budget. A diagnostic-only freeze does not automatically authorize large independent confirmation.

For an existing workspace, `workspace_status` returns cumulative jobs and budgets; `list_workspace_artifacts` discovers current notes, exports and analysis files. Read saved source-bound results instead of rerunning completed batches. `preview_edit_from_arrays` supports numeric references; ordinary `preview_edit` requires actual numeric arrays. Domain errors return their original cause and an argument path when available. Fix the indicated field; do not raise weight budgets to make a rejected plan pass.
